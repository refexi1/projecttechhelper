### Application

Creating an application for users that require help with technical difficulties with easy to use interface. Our app focuses on popular Operating Systems such as Windows 11, macOS, Linux variants and Android/IOS versions. 

### Why this application is needed

There are many users that encounter variety of issues with laptops and other applications, therefore an AI devoted to resolve those issues, from "PC won't turn on" to "This software is not functioning correctly" could help users. Structured JSON is also laid out into very readable form in our UI, which makes reading and pinpointing the issue faster for the user.

### Why use AI in this Application

AI is required, since it contains many Operating Systems and different devices; Laptops and phones. AI gives plenty of flexibility when it comes to giving proper solutions to a detailed issue.
